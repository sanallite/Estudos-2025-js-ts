Exemplos de CSS Transitions

Passe o mouse sobre os elementos para ver as transições.

1. Transição de Cor

A cor muda suavemente de azul para vermelho quando você passa o mouse sobre o elemento.
transition: background-color 0.5s ease-in-out;

2. Transição de Tamanho (Scale)

O elemento aumenta 20% de tamanho (escala) quando você passa o mouse sobre ele.
transition: transform 0.3s ease-out;

3. Transições Múltiplas

Várias propriedades são animadas simultaneamente: cor, formato (border-radius) e rotação.
transition: background-color 0.5s, border-radius 0.8s, transform 0.3s;

4. Transição com Delay

A animação começa após um pequeno atraso de 0.2 segundos.
transition: left 0.5s ease-in-out 0.2s;

5. Diferentes Timing Functions

Passe o mouse sobre toda a área para comparar diferentes funções de timing.

linear
ease
ease-in
ease-out
ease-in-out
cubic-bezier
Diferentes funções de timing alteram a velocidade da animação ao longo do tempo.

6. Sombra e Opacidade

A sombra aumenta e a opacidade muda ao passar o mouse, com tempos diferentes para cada propriedade.
transition: box-shadow 0.3s ease-out, opacity 0.5s ease-in;
